# pavanvenigalla.vercel.app

Portfolio of **Pavan Satya Krishna Venigalla** — Data Analytics Engineer.
Built with Astro, React islands and Tailwind, deployed as static files on Vercel.

---

## Running it

This project needs **Node 22.23.4 or newer** (Astro 7's floor). An `.nvmrc` is included:

```bash
nvm use            # picks up Node 26 from .nvmrc
npm install
npm run dev        # http://localhost:4321
```

| Script            | What it does                                    |
| ----------------- | ----------------------------------------------- |
| `npm run dev`     | Dev server with hot reload                      |
| `npm run build`   | Static build into `dist/`                       |
| `npm run preview` | Serve the built output locally                  |
| `npm run check`   | Astro + TypeScript diagnostics                  |

## Where the content lives

All copy is in `src/data/`. Nothing is hard-coded in markup, so the résumé page,
the case studies, the About timeline and the JSON-LD block can never disagree
with each other.

| File            | Holds                                                     |
| --------------- | --------------------------------------------------------- |
| `site.ts`       | Identity, contact links, SEO defaults, education, certs     |
| `roles.ts`      | Work history and résumé bullets                             |
| `projects.ts`   | The six case studies                                        |
| `skills.ts`     | Skill groups, mirroring how the résumé groups them          |
| `pipeline.ts`   | Stages behind the interactive lineage explorer              |
| `seed.sql`      | Synthetic warehouse built at runtime by DuckDB              |
| `queries.ts`    | Starter queries and schema summary for the playground       |

**To update the résumé**, edit `roles.ts` and `site.ts`, then replace
`public/resume.pdf` so the downloadable copy matches the page.

## The two interactive pieces

**`/pipeline`** — a medallion lakehouse rendered as a clickable lineage DAG.
Each stage carries its purpose, the engineering decisions that matter there, a
representative transformation, and the validation that gates it. Driven entirely
by `src/data/pipeline.ts`.

> The code samples are illustrative, written for this site. They are not source
> from any client system.

**`/sql`** — DuckDB compiled to WebAssembly, running in the visitor's tab over a
star schema of pipeline-run and validation telemetry. The data is generated by
`seed.sql` under a fixed `setseed()`, so it adds nothing to the bundle and every
visitor sees identical numbers. There is a planted incident in it: one pipeline
reports success while silently dropping ~40% of its rows.

DuckDB's WASM payload (~10 MB compressed) loads from its official CDN, and only
after an explicit click — nothing heavy is fetched for visitors who never open
the playground.

## Contact form

The form posts to [Web3Forms](https://web3forms.com). Set an access key:

```bash
cp .env.example .env
# then set PUBLIC_WEB3FORMS_KEY=your-key
```

Add the same variable to the Vercel project's environment variables.

**Without a key the page renders direct email links instead of a form.** That is
deliberate: a form that silently discards messages is worse than no form.

## Deploying

Vercel auto-detects Astro and needs no configuration beyond:

- **Build command** `npm run build`
- **Output directory** `dist`
- **Environment** `PUBLIC_WEB3FORMS_KEY`

`package.json` pins `engines.node >= 22.23.4` so Vercel selects a compatible runtime.

`vercel.json` declares the framework and build command in the repo rather than
relying on dashboard settings, and sets caching: everything under `/_astro` is
content-hashed by the build, so those files are served `immutable` with a
one-year max-age, while HTML stays revalidated. Note that Vercel validates
`vercel.json` strictly and rejects any key outside its schema — including
comment fields.

## Regenerating the social card

`public/og.png` is generated, not hand-drawn:

```bash
node scripts/generate-og.mjs
```

Edit the SVG in that script to change it.
